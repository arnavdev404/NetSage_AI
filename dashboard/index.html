About NetSage AI

NetSage AI diagnoses Cisco Packet Tracer lab faults by reading a symptom and show-command output, then using Google Gemini AI to pinpoint the root cause, classify the OSI layer, and suggest a step-by-step Internetwork Operating System fix.

Responsible AI policy: Every AI diagnosis must be approved by a human before any fix is applied. All decisions are tracked in the Responsible AI audit log.

Step-by-Step Guide
1

Browse the Case Library

Go to the Cases tab to explore all 30 lab scenarios. Use the search bar or category and priority filters to quickly find a specific fault type. Click any row to expand the full case details including show-command output.

Tip: Filter by Critical to see the most serious network security gaps.
2

Run the Rule Checker

Go to the Rule Checker tab and select a case. The system instantly applies 14 deterministic rules against the show-command text — no API or internet needed. Each violation shows the severity level and exact Internetwork Operating System fix command.

Tip: Start here before AI — the rule checker identifies most common faults instantly.
3

Review AI Diagnoses

Go to the AI Diagnosis tab to see 8 real Gemini AI results. Each card shows confidence level, OSI layer, root cause explanation, evidence quoted from show outputs, the recommended next diagnostic command, and Internetwork Operating System fix steps.

Tip: Click any card header to expand the full diagnosis detail.
4

Submit a Human Review

Go to the Human Review tab. Select a case, read the AI diagnosis, then record your verdict: Accept (AI is correct), Edit (partially right — enter correction), or Reject (AI is wrong — enter correct answer). Every review is saved permanently.

Tip: This is the most important step. Never apply a network fix without human verification.
5

Explore the Dashboard

Go to the Dashboard tab for visual analytics — cases by category, AI verdict breakdown, OSI layer distribution, severity breakdown, and the full Responsible AI audit log showing all human corrections.

Tip: The audit log is great for a presentation — it shows where AI went wrong and why.
